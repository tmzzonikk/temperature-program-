# temperature-program-

programa em C que permite a conversão de temperaturas entre Celsius e Fahrenheit!!

exemplo de funcionalidade do programa:
-- CONVERSOR DE TEMPERATURA --
C. celcius para fahrenheit
F. fahrenheit para celcius
A temperatura esta em celcius (C) ou fahrenheit (F)?: C
coloque a temperatura em celcius: 25
25.0 celcius é igual a 77.0 fahrenheit!

biblioteca ultilizada: <stdio.h>

projeto feito para questões de estudo da língua, livre para qualquer tipo de modificação
